## GPU 供电架构总览 {#供电架构}

现代 GPU 不是一块"通上电就能用"的芯片。它内部有多个不同的电压域，每个域由独立的 VRM（电压调节模块）供电，并遵循严格的**上电时序**——前一级电压正常输出后，才会开启下一级。

### 输入电压

| 输入源 | 电压 | 功率 | 来源 |
|--------|------|------|------|
| PCIe 金手指 12V | 12V | ~75W | 主板 PCIe 插槽 |
| PCIe 金手指 3.3V | 3.3V | ~10W | 主板 PCIe 插槽 |
| 外接 6-Pin | 12V | ~75W | 电源线 |
| 外接 8-Pin | 12V | ~150W | 电源线 |

RTX 2070 公版使用一个 8-Pin + 一个 6-Pin，最大功耗约 215W。

### 板载电压域

从 12V 和 3.3V 输入开始，板载 VRM 逐级生成以下电压：

| 电压域 | 典型值 | 作用 | 对地阻值参考 |
|--------|--------|------|-------------|
| **5V 辅助** | 5.0V | PWM 芯片供电、风扇控制 | >1kΩ |
| **1.8V (VDD18)** | 1.8V | GPU 逻辑初始化、I/O | ~200-600Ω |
| **PEXVDD** | ~1.0V | PCIe 桥接芯片供电 | ~100Ω |
| **NVVDD / MSVDD** | 0.7-1.0V | GPU 核心供电 | **0.1-0.8Ω（极低，非短路）** |
| **FBVDD** | 1.25-1.35V | GDDR6 显存供电 | 20-60Ω |

### 关键认识：NVVDD 的"假短路"

GPU 核心供电（NVVDD）的对地阻值通常只有 **0.1Ω ~ 0.8Ω**——这在万用表蜂鸣档下会直接报警。**这是正常的，不是短路！** 因为 GPU 核心需要几十到上百安培的电流，内部并联了大量低阻值通路。

判断核心是否短路的有效方法不是测 NVVDD 对地，而是**测 12V 到 NVVDD 之间是否有低阻值通路**——如果 12V 直接连到核心（上管击穿），那才是致命短路。

## 金手指核心供电与关键信号针脚 {#金手指针脚}

RTX 2070 使用标准 PCIe x16 接口。定义如下：

- **A 面**：正面（有芯片/散热器的一面）
- **B 面**：背面（有背板/贴片电容的一面）
- 针脚编号从靠近挡板（防呆口左侧）向右递增

### 防呆口左侧（1-11 脚）

| 针脚 | 名称 | 正常对地阻值 | 作用 |
|------|------|-------------|------|
| A1, B1, B2, B3 | **12V (PCIe)** | ~400Ω - 无穷大 | PCIe 主板 12V 总供电 |
| A2, A3, B8 | **12V (辅助)** | ~400Ω - 无穷大 | PCIe 逻辑与辅助 12V |
| A9, A10, B9, B10 | **3.3V (PCIe)** | ~300Ω - 600Ω | BIOS / 逻辑控制芯片供电 |
| A11 | **PERST#** | ~400-600Ω | PCIe 复位信号 |

### 防呆口右侧（12 脚起）

| 针脚 | 名称 | 正常对地阻值 | 作用 |
|------|------|-------------|------|
| B12 | **SMBCLK** | ~500-700Ω | I2C 总线时钟线 |
| B13 | **SMBDAT** | ~500-700Ω | I2C 总线数据线 |
| A13, A14 | **REFCLK+/-** | ~400-600Ω | PCIe 参考时钟输入 |

### PCIe 数据线阻值检查

A 面和 B 面的 PCIe 数据接口与 GPU 核心有 32 路直连数据总线。**每一路的对地阻值应基本相等**（误差在几个点以内）。如果某一路明显偏低或偏高，极大概率意味着 GPU 核心损坏。

- B 面 PCIE 数据接口对地阻值：~300Ω
- A 面 PCIE 数据接口（耦合电容处）：~200Ω
- A13/A14 时钟信号：~800Ω（直连 GPU，异常意味着核心损坏）

> **测量方法**：万用表二极管档（蜂鸣档），红表笔接地（挡板或螺丝孔），黑表笔测对应针脚。

## 板载核心电压测试点 {#板载电压测试}

### 1. 12V 输入端（PCIe & 8pin 接口）

- **测量位置**：输入端保险丝（Fuse）或大型贴片电容两端
- **对地阻值**：几百欧姆以上
- **故障判断**：若接近 0Ω，表明 12V 存在主供电短路，**严禁上电**

### 2. 5V 辅助供电

- **测量位置**：靠近 PWM 供电芯片（如 UP9512P）旁的小型电感
- **正常阻值**：~1kΩ - 几 kΩ
- **正常电压**：稳定 5.0V
- **故障判断**：阻值过低 → 可能 MOSFET 驱动器短路

### 3. 1.8V 逻辑供电 (VDD18)

- **测量位置**：显卡中下部或显存附近的小电感
- **正常阻值**：~200-600Ω
- **正常电压**：1.8V（GPU 初始化的先决条件）
- **故障判断**：PEX + 1.8V 同时短路 → 多为核心损坏

### 4. PEXVDD（PCIe 桥接供电）

- **正常阻值**：~100Ω
- **正常电压**：0.95V - 1.0V
- **作用**：负责 PCIe 信号通讯
- **故障判断**：短路则极可能直接烧毁核心

### 5. NVVDD / MSVDD（GPU 核心供电）

- **测量位置**：显卡上排成一列的大型电感（通常 6-8 相）
- **正常阻值**：**0.1Ω ~ 0.8Ω（极低，非短路！）**
- **正常电压**：点亮状态下约 0.7V - 1.0V
- **注意**：20 系核心供电冷态对地约 0.1Ω，这是正常值

### 6. FBVDD（GDDR6 显存供电）

- **测量位置**：显存颗粒旁边的 1-2 个独立电感
- **正常阻值**：~20-60Ω
- **正常电压**：约 1.25V - 1.35V
- **注意**：三星显存的话，显存供电对地约十几欧姆

## 故障排查顺序：万用表测法 {#排查顺序}

```
[1. 离线阻值排查] → [2. 上电电压测试] → [3. 信号与时钟] → [4. 故障定位]
```

### 第一步：断电测量对地阻值（防烧板）

**工具**：万用表二极管/蜂鸣档

**操作**：
1. 红表笔接地（挡板或螺丝孔），黑表笔测量各点
2. 测量顺序：

| 测量点 | 正常值 | 异常含义 |
|--------|--------|---------|
| PCIe 金手指 12V (A1/B1) | >400Ω | 接近 0Ω = 12V 短路，**禁止上电** |
| 外接 8+6pin Pin 1-3 | >400Ω | 接近 0Ω = 12V 短路 |
| PCIe 3.3V (A9/A10) | 300-600Ω | 过低 = 3.3V 短路 |
| 核心电感 (LR22) | 0.1-0.8Ω | **这是正常的，不是短路** |
| 显存电感 (LR47) | 20-60Ω | 过低 = 显存或核心问题 |
| 1.8V 电感 (1R0/R47) | 200-600Ω | 过低 = 可能核心损坏 |
| PEXVDD | ~100Ω | 过低 = PCIe 桥接短路 |
| 5V 电感 | >1kΩ | 过低 = MOSFET 驱动器问题 |

> ⚠️ **安全警告**：如果任何 12V 线路对地蜂鸣报警（接近 0Ω），**严禁插主板上电**，否则会烧毁主板或电源！

### 第二步：上电测量时序电压

阻值正常后，将显卡插上测试平台，按开机键后按顺序测量：

```
12V / 3.3V → 5V → 1.8V → PEXVDD → NVVDD (核心) → FBVDD (显存)
```

**每一步的电压应在前一级正常后才会产生。** 如果某一步电压缺失，后续电压通常也不会产生。

| 测试点 | 期望电压 | 测量位置 |
|--------|---------|---------|
| 12V 输入 | 12.0V | 金手指/外接电源 |
| 3.3V | 3.3V | 金手指 A9/A10 |
| 5V 辅助 | 5.0V | 5V 电感输出端 |
| 1.8V | 1.8V | 1.8V 电感输出端 |
| PEXVDD | 0.95-1.0V | PEX 电感输出端 |
| NVVDD | 0.7-1.0V | LR22 大电感 |
| FBVDD | 1.25-1.35V | LR47 电感 |

### 第三步：测量关键信号

所有电压正常但仍然黑屏时，检查关键信号：

- **A11 脚 PERST#**：上电瞬间应从 0V 跳变为 3.3V。维持 0V = 主板未识别到显卡或 GPU 未完成初始化
- **A13/A14 REFCLK**：PCIe 参考时钟，需要示波器确认波形
- **SMBCLK/SMBDAT (B12/B13)**：I2C 总线，显卡 BIOS 读取通道

### 第四步：故障定位与隔离

使用分段隔离法逐步缩小范围：
1. 拆除散热器，清洁导热膏
2. 用放大镜检查 PCB 背面有无烧灼点
3. 逐个测量供电相位的 MOSFET/DrMOS
4. 对比同一型号好卡的阻值数据

## 常见故障类型与诊断 {#常见故障}

### 故障类型 1：完全不通电（插上后电源保护）

| 可能原因 | 诊断方法 | 预后 |
|---------|---------|------|
| 12V 主供电短路 | 测金手指/外接 12V 对地阻值 ≈ 0Ω | 需追踪短路元件 |
| 上管（High-side MOSFET）击穿 | 测 12V 到 NVVDD 之间低阻值 | **GPU 核心很可能已死** |
| 下管（Low-side MOSFET）击穿 | NVVDD 对地短路，12V 正常 | GPU 可能幸存，可修 |
| 输入保险丝熔断 | 测保险丝两端通断 | 更换保险丝 |

### 故障类型 2：有电无显示（黑屏但风扇转）

| 可能原因 | 诊断方法 | 预后 |
|---------|---------|------|
| 1.8V / PEXVDD 缺失 | 测对应电感电压 | 检查 PWM 芯片和使能信号 |
| 核心供电未启动 | 测 NVVDD 电压 | 检查 PGOOD 信号链 |
| 显存供电异常 | 测 FBVDD 电压和阻值 | 显存颗粒可能损坏 |
| PERST# 无效 | 测 A11 脚电压 | 检查主板或 GPU 初始化 |
| 显存虚焊/连锡 | 测显存数据线阻值（背面耦合电容） | 需要重焊 |

### 故障类型 3：花屏 / 画面异常

| 可能原因 | 诊断方法 | 预后 |
|---------|---------|------|
| 显存颗粒损坏 | 逐颗测阻值对比 | 更换坏颗粒 |
| 显存虚焊 | 烘烤后观察 | 重新植球 |
| GPU 核心降级 | GPU-Z 检测参数 | 可能核心老化 |
| 散热不良 | 测温度 | 更换散热 |

### 故障类型 4：使用中突然黑屏/重启

| 可能原因 | 诊断方法 | 预后 |
|---------|---------|------|
| VRM 过热保护 | 热成像仪扫描供电区 | 改善散热 |
| 显存温度过高 | 红外测温 | 改善显存散热 |
| 核心虚焊 | 压核测试（按压 GPU 核心） | 重新植球 |
| 供电相位不均衡 | 逐相测电压 | 更换损坏 DrMOS |

## VRM 供电模块诊断 {#vrm-诊断}

### VRM 基本原理

GPU 核心需要 0.7-1.0V 电压，但需要几十到上百安培电流。VRM（电压调节模块）将 12V 降压至此，每相由两个 MOSFET 组成：

- **上管（High-side）**：连接 12V 和电感
- **下管（Low-side）**：连接电感和地

PWM 控制器以高频（300kHz - 数 MHz）交替开关这两个管子，通过电感平滑输出目标电压。

### DrMOS 集成化

现代显卡（包括 RTX 2070）多使用 DrMOS 集成封装——将驱动器、上管和下管封装在一个 QFN 芯片内。RTX 2070 的 8 相核心供电很可能使用 DrMOS。

### MOSFET 击穿诊断

| 击穿类型 | 对地表现 | 对 GPU 的影响 | 修复可行性 |
|---------|---------|-------------|-----------|
| 上管击穿 | 12V 直连 NVVDD | **几乎必杀核心**（12V 直接灌入） | 极低 |
| 下管击穿 | NVVDD 对地短路 | GPU 可能幸存 | 可修（换 DrMOS） |
| 驱动器损坏 | 相位无输出 | 可修 | 可修（换 PWM/驱动器） |

### 诊断步骤

1. **目视检查**：DrMOS 是否有烧灼痕迹、PCB 是否变色
2. **测 12V 到 NVVDD**：低阻值 = 上管击穿
3. **测 NVVDD 对地**：短路 = 下管击穿或核心短路
4. **逐相隔离**：如果多相并联，需要逐个断开测量
5. **热成像**：上电后快速扫描，异常发热的相位即为故障相

## GPU 上电时序详解 {#上电时序}

理解上电时序是诊断"有电无显"的关键。GPU 不是所有电压同时产生的，而是严格按顺序：

```
1. 12V / 3.3V 输入（PCIe + 外接）
   ↓
2. 5V 辅助（从 12V 降压）
   ↓
3. 1.8V VDD18（从 3.3V 降压）
   ↓
4. PEXVDD ~1.0V（PCIe 桥接供电）
   ↓
5. FBVDD 1.35V（显存供电）
   ↓ PGOOD 信号
6. NVVDD 0.7-1.0V（核心供电）
   ↓
7. GPU 初始化 → PERST# 响应 → 正常工作
```

**关键依赖关系**：
- PEXVDD 和 1.8V 都直连 GPU 核心，短路几乎必杀核心
- FBVDD 的 PGOOD 信号通常是 NVVDD 的使能条件
- 如果时序链中任何一环断裂，后续电压都不会产生

### 时序诊断实例

**症状**：核心电压（NVVDD）无输出

**排查路径**：
1. 检查 12V 是否到达 PWM 芯片输入端
2. 检查 5V 辅助是否正常（PWM 芯片需要 5V 才能工作）
3. 检查 1.8V 是否正常
4. 检查 PEXVDD 是否正常
5. 检查 FBVDD 是否正常并发出 PGOOD
6. 检查 NVVDD PWM 芯片的 EN（使能）引脚是否收到信号
7. 如果 EN 正常但仍无输出 → PWM 芯片或 DrMOS 损坏

## 专业点位图获取与使用 {#点位图}

当万用表测量发现异常后，需要通过点位图（Boardview）精确找到 PCB 上的对应元件和走线。

### 推荐软件

| 软件 | 类型 | 说明 |
|------|------|------|
| **OpenBoardView** | 免费开源 | 支持 .fz / .cad 等格式 |
| **FlexBV** | 商业 | 功能更全面 |
| **Compañero** | 免费 | 界面友好 |

### 图纸搜索关键词

在维修论坛（迅维网、TechPowerUp 论坛、Vinafix 等）搜索：

- `RTX 2070 Boardview`
- `PG160 boardview`（PG160 = NVIDIA RTX 2070 公版 PCB 编号）
- `RTX 2070 schematic`
- `TU104 boardview`

### 使用方法

1. 用 OpenBoardView 打开 `.cad` 或 `.fz` 文件
2. 在搜索栏输入元件标注（如 `LR22`、`LR47`、`UP9512`）
3. 软件高亮显示该元件在 PCB 上的位置
4. 搜索网络名（如 `NVVDD`、`12V`、`PERST`）自动标注所有连接点
5. 查看测试点（Test Point）位置，方便万用表探测

### DC 电源限流上电法

推荐使用**可调 DC 电源**替代 ATX 电源进行初次上电测试：

1. 将 DC 电源电压调至 12V，电流限制设为 **0.5A**（极小）
2. 连接到显卡 12V 输入
3. 上电观察电流：
   - **0A 或极低**：可能断路、PWM 未启动
   - **0.5A 并持续上升**：存在短路，电源在限流
   - **正常待机**：约 0.1-0.3A（散热器凉，GPU 待机）
4. 如无异常，逐步提高电流限制到 1A → 2A → 5A
5. 触摸各 DrMOS、PWM 芯片，检查是否有异常发热

## 安全注意事项 {#安全须知}

### 防烧板原则

1. **先测阻值再上电**：永远先做离线阻值检查，确认无 12V 短路后才上电
2. **限流上电**：初次上电使用 DC 电源限流，而非直接接 ATX
3. **无散热器不上电超过 10 秒**：GPU 核心无散热器时，上电时间极短即可过热
4. **不要乱拆显存**：在不跑 MATS（显存测试工具）的情况下乱拆显存，成功率极低且浪费时间
5. **拆显存后要测信号线阻值**：拆了显存不打信号线阻值就装回去，等于白干

### PEXVDD / 1.8V / 显存供电的致命性

PEXVDD、1.8V 供电和显存供电均**直接连接 GPU 核心**。一旦这些供电短路，核心损坏概率约 **99.9%**。虽然有移除短路元件可能恢复的极低概率案例，但绝大多数情况下核心已永久报废。

**选购二手显卡避坑**：检测到 PEXVDD、1.8V 或显存供电短路 → 一律排除，不要抱侥幸心理。

### 焊接安全

- 热风枪温度：拆贴片 MOSFET 约 **350-400°C**，拆 BGA 约 **230-250°C**（配合预热台）
- 更换元件必须使用**同型号**（后缀编码完全一致）
- 操作前戴防静电手环，避免静电击穿
- 焊接后必须用万用表复测阻值，确认无连锡

## 总结

GPU 故障排除是一项需要耐心和系统思维的工作。核心思路：

1. **先看后测**：目视检查能发现大量问题（烧灼、缺件、虚焊）
2. **先测阻值再上电**：防止二次损坏是第一要务
3. **按时序排查**：理解电压产生顺序，从源头往下游追
4. **对比是好方法**：有同型号好卡对比阻值，效率提升十倍
5. **PEXVDD/1.8V 短路 = 核心大概率报废**：不要浪费时间在不可修的板子上
6. **善用点位图**：OpenBoardView + 正确的图纸文件，让维修事半功倍
